# Боты команды: лендинг

Статическая страница о пяти ботах: покер-планинг, фасилитатор, разбор спринта,
Поздравлятор и пост-мейкер. Адаптивная, с тёмной темой.

Сайт: https://egorbeezer.github.io/bots-landing/

Исходники основного проекта живут в корпоративном GitLab. Здесь только
публичная витрина: `index.html` и скриншоты в `screens/`.
